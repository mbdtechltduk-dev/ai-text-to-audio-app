## Overview

AI Text to Audio Generator is a Flutter application
designed to simplify speech generation, voice recording
and audio-related productivity workflows.

The application brings multiple audio tools into a
modern dark-themed mobile interface.

## Features

### AI Text to Audio
- Text input for speech generation
- Voice selection interface
- Generate Speech action
- Recently generated audio list

### AI Prompt Generator
- Prompt input
- Generated script display
- Generate Prompt action
- Prompt history interface

### Voice Recorder
- Voice recording interface
- Recording duration display
- Saved recording list
- Playback controls

### Voice Enhancer
- Dedicated voice enhancement tool
- Audio-focused workflow

### History & Settings
- Recent generations
- Recording history
- Application settings

### Premium Experience
- Premium upgrade entry point
- Subscription-oriented interface

These product areas are visible in the supplied
App Store screenshots. Their complete runtime
